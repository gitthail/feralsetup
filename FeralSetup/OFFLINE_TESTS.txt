v3.9.0 — independent fixed Numbers and QE packages

Lua 5.1 simulations check the actual setup/form/bindings/restore commands:
- One fixed map per package; no runtime selection table or switching function.
- First four physical slots: direct builder, direct finisher, bleed builder,
  bleed finisher. Numbers keys 1-4 map directly to slots 1-4.
- Human, Cat and Bear pages, personal item preservation and stale A/B state.
- Old switch commands/arguments make no changes and explain their removal.
- Binding read-back, rollback after rejected or silently ignored writes,
  combat/cursor guards, Windows Alt aliases and unrelated personal shortcuts.
- Snapshot/recovery includes macros bound directly by name.
- Protected heals, explicit mouseover, focus, self-cast and Shift+W targeting.
- Dynamic learned form indices and learned/unlearned stealth opener fallbacks.
- Macro limits, levelling events, guide scripts and single-folder install ZIPs.

These are simulated API checks, not a live-client test. Actual key delivery,
casting, failed-cast autoUnshift, movement/modifier behaviour and OS shortcut
interception still require checking in game. A successful file sync does not
rebuild saved bars: follow README.txt's setup steps in all three forms.
