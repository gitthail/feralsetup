# B — Q/E · v3.9.1

Attacks on **Q/E and Shift+Q/E**, controls on **1/2**.

**[Download B — FeralSetup.zip](https://github.com/gitthail/feralsetup/raw/refs/heads/main/variants/B-qe/FeralSetup.zip)**

| Key | Cat | Bear | Human |
| --- | --- | --- | --- |
| Q | Claw | Maul | Moonfire |
| E | Ferocious Bite | Primal Bite | Wrath |
| Shift+Q | Rake | Swipe | Starfire |
| Shift+E | Rip | Lacerate | Hurricane |
| 1 | Dash / stealthed Pounce | Bash | Roots |
| 2 | Cat Charge | Bear Charge | Hibernate |

Shift+1/2 focus eligible controls. Shift+W, Z or 4 is Faerie Fire; Shift+Z targets focus. Alt/Cmd+R generates resources: Cat Shifting Power, Bear Enrage, human self-Innervate. See the [full key map](FeralSetup/KEYBINDS.txt).

Extract the ZIP and move its **FeralSetup** folder into `Interface/AddOns`. Alternatively, copy this directory's complete **FeralSetup** folder. Install only one variant at a time, replacing the previous FeralSetup folder when changing variants.

Restart WoW, then out of combat:

1. Human form, main action page 1: `/fs setup`.
2. Enter Cat: `/fs form`.
3. Enter Bear: `/fs form`.
4. Check the pages, then `/fs save`.

Both Windows and Mac use this same package. Use Alt on Windows; Alt or Command on Mac. There is no in-game A/B switch. Personal item slots are preserved; `/fs items` reports their contents.

The folder and ZIP include the matching **Guide.html**, **Leveling.html** and **KEYBINDS.txt**, readable offline. [A — Numbers](../A-numbers) is the alternative layout.
