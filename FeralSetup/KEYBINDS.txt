BOTH LAYOUTS
Z = Faerie Fire; Shift+Z = focus Faerie Fire. Cmd/Alt+Z = healing potion.
R = Cat Shred / Ravage*; Bear Demoralizing Roar; human Soothe Animal.
6 = Bear Growl; Shift+6 = focus Growl.
B = Cat Prowl toggle; Bear Challenging Roar; human empty.
J = Cat Cower; Cmd/Alt+J = Bear Frenzied Regeneration.
Alt+Q = Cat Dash even in stealth. Cmd+Q is NOT bound (macOS Quit).
* R uses Shred in stealth until Ravage is learned. The control key stays
Dash in stealth until Pounce is learned. Dash must itself be learned.
Run /fs update after learning those spells to refresh the macros.
Learned spells do not fall back on energy/range/position/cooldown failure.

EXPLICIT MOUSEOVER
F Rejuvenation; G Regrowth; 5 Healing Touch; C Remove Curse;
V Cure/Abolish Poison; Y Innervate; 8 Mark of the Wild; 9 Thorns.
Cmd/Alt forces self. Otherwise living friendly hover -> friendly target -> self.
Shift alone is inactive on these friendly spells. Ctrl has no special role.

T Roots; X Hibernate, in every form; Shift+T/X = hostile focus.
Controls (including Pounce/Bash/Charge/Growl/FF): Shift = hostile focus;
otherwise living hostile hover -> living hostile selected target.
Invalid focus does NOT fall back. An out-of-range hover stays the chosen
recipient; range/immunity/line of sight are not macro fallback conditions.
7 Moonfire: hostile hover -> hostile target (also on the human main page).
U Rebirth: dead friendly hover -> dead friendly target.
K Tranquility. No spell macro forcibly cancels form. Only H does.
Native mouseover is disabled; native self/focus modifiers are NONE.
autoUnshift=1 lets the client handle caster spells leaving form; the addon
cannot guarantee form retention on every client-side failed cast.

FORMS / MOVEMENT / FOCUS
Wheel up Cat, wheel down Bear. Unmodified repeats do not re-shift.
Cmd/Alt+wheel = deliberate form re-cast. Middle click = Aquatic/Travel.
H = explicitly leave form, stop casting and attacking.
Shift+Space = set focus (living hover, then target).
Cmd/Alt+Shift+Space = clear focus.
W/S forward/back; A/D strafe; Tab nearest enemy; Space jump.
Page Up/Down = camera zoom. Ctrl and Shift+R remain available.
Shift+D = toggle native damage meter (visibility follows game settings).
