# A — Numbers · v3.9.1

Attacks on **1–4**, controls on **Q/E**. This is the currently installed layout.

**[Download A — FeralSetup.zip](https://github.com/gitthail/feralsetup/raw/refs/heads/main/variants/A-numbers/FeralSetup.zip)**

| Key | Cat | Bear | Human |
| --- | --- | --- | --- |
| 1 | Claw | Maul | Moonfire |
| 2 | Ferocious Bite | Primal Bite | Wrath |
| 3 | Rake | Swipe | Starfire |
| 4 | Rip | Lacerate | Hurricane |
| Q | Dash / stealthed Pounce | Bash | Roots |
| E | Cat Charge | Bear Charge | Hibernate |

Shift+Q/E focus eligible controls. Shift+W or Z is Faerie Fire; Shift+Z targets focus. Alt/Cmd+R generates resources: Cat Shifting Power, Bear Enrage, human self-Innervate. See the [full key map](FeralSetup/KEYBINDS.txt).

Extract the ZIP and move its **FeralSetup** folder into `Interface/AddOns`. Alternatively, copy this directory's complete **FeralSetup** folder. Install only one variant at a time, replacing the previous FeralSetup folder when changing variants.

Restart WoW, then out of combat:

1. Human form, main action page 1: `/fs setup`.
2. Enter Cat: `/fs form`.
3. Enter Bear: `/fs form`.
4. Check the pages, then `/fs save`.

Both Windows and Mac use this same package. Use Alt on Windows; Alt or Command on Mac. There is no in-game A/B switch. Personal item slots are preserved; `/fs items` reports their contents.

The folder and ZIP include the matching **Guide.html**, **Leveling.html** and **KEYBINDS.txt**, readable offline. [B — Q/E](../B-qe) is the alternative layout.
